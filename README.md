# Ostrov

Полифонический синтезатор (VST3 / AU / Standalone) для Ableton и других DAW.
Мягкие «аналоговые» волны, ноты из своего лада с чистым строем и плывущее пространство.

## Алгоритмы
| Алгоритм | Что это | Timbre | Color | Motion | Body |
|---|---|---|---|---|---|
| **Bloom** | фазовая модуляция на мягких волнах, глубина от силы нажатия | глубина модуляции | волна-несущая | ансамбль-расстройка, обратная связь | соотношения операторов |
| **Drift** | VCO треугольник→пила→меандр в тёплый 4-полюсный фильтр | срез | форма волны | дрейф (LFO с некратными частотами) | резонанс |
| **Fold** | осцилляторы через волну-передаточную функцию (фолдер) | драйв | форма складки | дыхание драйва | второй осциллятор (×0.5…×2) |
| **Bell** | возбудитель «бьёт» по модальным резонаторам | яркость удара | колокол / стекло / гармоники / гонг | мерцание | длина звучания |
| **Choir** | VCO через форманты, морфинг гласных | дыхание | гласная u-o-a-e-i | вибрато, дрейф формант | размер голоса |
| **Breath** | шум в банк резонаторов, настроенных на ноту | шум → тон | гармоничность | трепет | яркость |

## Лад и строй
- **Круг лада**: клик по ноте включает или выключает её, Shift-клик (или правый клик) делает её тоникой.
- **Scale Lock**: любая нота с клавиатуры притягивается к ближайшей ступени лада.
- **Tuning**:
  - *Equal* — равномерный строй;
  - *Just (root)* — чистые интервалы от тоники;
  - *Just (adaptive)* — чистые интервалы от самой нижней зажатой ноты, плавная перестройка (аккорды без биений).

## Пространство
Plate (плейт с модуляцией), Tape (ленточный дилей с wow/flutter), Tape+Plate.

## Установка на Mac
1. На странице **Actions** откройте последний успешный запуск и скачайте артефакт `Ostrov-mac`. Либо скачайте архивы со страницы **Releases**.
2. Распакуйте архивы и положите файлы в папки:
   - `Ostrov.vst3` → `~/Library/Audio/Plug-Ins/VST3/`
   - `Ostrov.component` → `~/Library/Audio/Plug-Ins/Components/`
3. Плагин подписан ad-hoc, поэтому macOS может его блокировать. В Терминале снимите карантин:
   ```
   xattr -cr ~/Library/Audio/Plug-Ins/VST3/Ostrov.vst3 ~/Library/Audio/Plug-Ins/Components/Ostrov.component
   ```
4. В Ableton: Settings → Plug-Ins → Rescan.

## Сборка
Всё собирает GitHub Actions (macOS universal). Демо-WAV всех алгоритмов собираются в артефакт `Ostrov-demo-audio`.

Локально (нужны CMake и Ninja или Xcode):
```
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --target Ostrov_VST3
```

## Структура
- `src/dsp/` — DSP-ядро без зависимостей: волны, блоки, алгоритмы, эффекты, строй.
- `src/Plugin*` — обёртка JUCE и интерфейс.
- `tools/render_demo.cpp` — офлайн-рендер демо без хоста.
